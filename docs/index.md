# 私たちについて


## 会社概要
私たちは日本市場向けソフトウェア開発に特化し、中国を拠点にオフショア体制でプロジェクトを推進しています。豊富なエンジニアリソースと競争力のあるコストを強みに、円建てでの取引にも対応し、スムーズで安心感のあるサービスを提供しています。

「より速く、より良く」を指針に、案件ごとに専任チームを配置し、高い集中力とスピード感で成果を出します。市場やニーズの変化を前提とし、柔軟な舵取りで最適なソリューションと体験をお届けします。

## チーム概要
メンバーは成長意欲の高い若手エンジニアが中心で、素早い意思決定と実行を得意としています。内省とオープンな対話を大切にし、学び合いながらプロダクト品質を磨き続けています。高い完成度にこだわり、その姿勢が一つひとつの成果物に反映されています。

組織としては標準化フェーズに入り、役割や責任が明確になったことで連携がより滑らかになりました。複雑な案件でも安定したアウトプットを出せるチーム力があり、持続的に高品質な成果を届けています。

私たちは常に変化を味方につけ、進化し続ける企業でありたいと考えています。自由闊達なカルチャーのもと、多様な視点や発想を歓迎しています。
